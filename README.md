# 🛒 Kbona — Para surpresinhas

Aplicação web desenvolvido como atividade da disciplina de **Desenvolvimento Web I** da **Universidade do Contestado (UnC) – Campus Mafra**. O sistema simula uma loja virtual completa voltada para a comercialização, permitindo o gerenciamento completo de inventário, clientes e vendas sem necessidade de *back-end*.

## Projeto

O objetivo principal é aplicar na prática os conceitos fundamentais de desenvolvimento web front-end, criando uma solução funcional para resolver necessidades concretas de organização, consulta e gerenciamento de informações comerciais, com persistência local de dados e interface moderna e responsivo.

---

## Funcionalidades

* **Dashboard Dinâmico:** Indicadores em tempo real calculados diretamente a partir dos registos armazenados (faturação, total de clientes, peças em estoque e vendas realizadas).
* **Gestão de Produtos (CRUD):** Cadastro, listagem, edição e exclusão de itens com validação de formulários e controlo de stock.
* **Gestão de Clientes (CRUD):** Registo de utilizadores com validação de CPF, e-mail e telemóvel.
* **Carrinho de Compras e Combos:** Adição de itens ao carrinho, simulação de parcelamento e cálculo automático de descontos progressivos baseados na variedade de categorias.
* **Histórico de Vendas:** Registo de pedidos com alteração de estados (Pendente, Concluído, etc.).
* **Pesquisa, Filtros e Ordenação:** Ferramentas avançadas para localizar produtos e clientes rapidamente.
* **Persistência de Dados:** Utilização do `localStorage` para garantir que as informações não se percam ao recarregar a página.
* **Modo Escuro / Claro:** Alternância de tema integrada na interface.

---

##Utilizado

* **HTML5:** Estruturação.
* **CSS:** Estilização.
* **Bootstrap 5.3.3:** Framework CSS utilizado para grelhas, componentes visuais (modais, tabelas, *offcanvas*, *toasts*, *cards*) e responsividade.
* **JavaScript (Vanilla ES6+):** Manipulação dinâmica do DOM, regras de negócio, validações e gestão do armazenamento local (`localStorage`).
